Phylogenomic Overview — All Species in the Datasets

An angular overview of every bird in the project's two datasets — AVOTREX (610 extinct, data/Avotrex_*.csv) and AVONET (11,009 extant, data/DB_Avonet_BirdLife.csv) — grouped into the 39 orders of the shared taxonomy. A dashed backbone runs down the left; one elbow and band per order. Each band's height is a log scale of its species count; its width is split into era segments (brown → purple → red → blue). Hover any band for its order's composition and largest families.

This is intentionally a taxonomic overview, not a molecular phylogeny — there is no single published tree of all 11,619 species we can embed. The time-calibrated, storytelling ribbon tree lives on the honeycreeper page, the only region in the datasets with one.

What this is (and isn't)

  • Backbone. The topology is the shared taxonomy in the datasets (order → family → genus → species), so this is a taxonomic overview, not a molecular phylogeny — there is no single published tree of all 11,619 species we can embed. The elbow/band layout is a stylized dendrogram: it communicates grouping and relative scale, not evolutionary time. Band height is a log scale of species count (Passeriformes dwarfs everything, as it should).
  • Band color = era from each species' status code (EP/EPU prehistoric, EX/EH historical, EW/CR edge, else extant) — the same four-color scheme as the site's map and slider. The red/orange segments show where extinction is concentrated (Passeriformes + a few island orders); the brown shows where the deep, unrecorded losses hide (cormorant + penguin lineages).
  • Order-level aggregation by design: ~2,000 families and 11,000+ species would be unreadable as individual rows, so the overview stops at order and pushes family detail into the hover tooltip (top 8 by count, with their extinct totals).

Data: data/Avotrex_taxonomy_v1.csv · data/Avotrex_traits_v1.csv · data/DB_Avonet_BirdLife.csv (Sayol et al. 2024, AVOTREX). Era scheme: graphs/common.js.
